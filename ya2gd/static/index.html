1. Яндекс Диск

Как получить токен (3 минуты)
  1. Откройте oauth.yandex.ru/client/new, создайте приложение (платформа «Веб-сервисы», Redirect URI: https://oauth.yandex.ru/verification_code), доступ: Яндекс Диск REST API → «Чтение всего Диска».
  2. Вставьте ClientID сюда и нажмите «Получить токен»:
  3. Скопируйте показанный токен в поле выше и нажмите «Сохранить и проверить».

2. Google Drive

Как получить (5 минут)
  1. Создайте проект в Google Cloud, включите Google Drive API.
  2. «OAuth consent screen» / «Google Auth Platform»: тип External, добавьте себя в тестовые пользователи, потом нажмите Publish app (In production) — иначе вход будет слетать через 7 дней.
  3. «Credentials → Create credentials → OAuth client ID → Desktop app». Скопируйте ID и secret сюда.
  4. Нажмите «Войти в Google». Предупреждение «приложение не проверено» — это ваше приложение: «Дополнительно → Перейти».

Программа видит на Drive только то, что создала сама (доступ drive.file).

3. Раздел «Фото» (автозагрузка с телефона)

Зачем куки и как их взять (2 минуты)

Фото из безлимитной автозагрузки видны только в разделе «Фото», а официальный API Яндекса их не отдаёт. Сайт Диска получает их плоским списком (с размером и MD5) и выдаёт ссылку на оригинал каждого файла — программа делает то же самое, строго по одному файлу. Куки нужны и как запасной путь для «Файлов», если API Яндекса отвечает «410 Gone» (так бывает с октября 2026).

  1. Поставьте расширение Cookie-Editor (Chrome / Яндекс Браузер / Edge, Firefox).
  2. Откройте disk.yandex.ru/client/photo — там должны быть видны ваши фото.
  3. Нажмите значок 🍪 расширения → Export → Export as JSON (скопируется в буфер обмена).
  4. Вставьте в поле ниже и нажмите «Сохранить и проверить».

Куки живут от нескольких дней до нескольких недель. Когда устареют, программа поставит на паузу только то, что идёт через сайт, и напишет об этом наверху. Остальное продолжит переноситься. Обновите куки и нажмите «Старт». Куки — это доступ к вашему аккаунту: они хранятся только на этом компьютере, никому их не передавайте.

4. Буфер на диске компьютера

Необязательно. Без буфера маленькие файлы ждут в памяти, а большие видео идут напрямую Яндекс → Google кусками по 32 МБ. С буфером (рекомендуется, если на быстром диске есть 20–30 ГБ): файлы скачиваются с Яндекса, не дожидаясь Google, MD5 сверяется до загрузки, оборванное видео докачивается с места обрыва, а пока Google на паузе из-за суточного лимита, скачивание с Яндекса продолжается. Файлы из буфера удаляются сразу после проверки на Google. Файл больше буфера идёт напрямую.

5. Список файлов

Программа получает у Яндекса готовый плоский список всех файлов (имена, размеры, MD5) — ничего не скачивая. Затем для каждого файла отдельно запрашивает ссылку и переносит его.
«Старт» можно нажимать сразу: файлы попадают в очередь по мере получения списка.

Настройки

Каждый файл попадает на Drive ровно один раз — дублей между «Фото» и «Файлами» нет. Выберите до начала переноса: уже перенесённые файлы не перекладываются.
Подбирать число потоков к Яндексу автоматически: начинать с 3, прибавлять, пока Яндекс отвечает стабильно, и сбавлять при жалобах
Переносить раздел «Фото» (безлимит)
Переносить раздел «Файлы»
Если Яндекс долго не отдаёт оригинал фото — сохранить хотя бы превью (уменьшенную копию) в отдельную папку; когда оригинал перенесётся, превью удалится
Не заливать повторно файл, который уже лежит на Drive (то же имя, размер и MD5)
Проверять MD5 после загрузки
При запуске программы сам продолжать прерванный перенос
Запускать программу при входе в Windows (после перезагрузки или отключения света перенос продолжится сам — вместе с пунктом выше)
Открывать интерфейс отдельным окном (Edge/Chrome без адресной строки)
Число потоков и буфер применяются при следующем «Старте».
