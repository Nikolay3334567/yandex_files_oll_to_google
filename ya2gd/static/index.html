1. Яндекс Диск

Как получить токен
  1. Откройте oauth.yandex.ru/client/new, создайте приложение (платформа «Веб-сервисы», Redirect URI: https://oauth.yandex.ru/verification_code), доступ: Яндекс Диск REST API → «Чтение всего Диска».
  2. Вставьте ClientID сюда и нажмите «Получить токен»:
  3. Скопируйте показанный токен в поле выше и нажмите «Сохранить и проверить».

2. Google Drive

Как получить
  1. Создайте проект в Google Cloud, включите Google Drive API.
  2. «OAuth consent screen» / «Google Auth Platform»: тип External, добавьте себя в тестовые пользователи, потом нажмите Publish app (In production) — иначе токен будет умирать через 7 дней.
  3. «Credentials → Create credentials → OAuth client ID → Desktop app». Скопируйте ID и secret сюда.
  4. Нажмите «Войти в Google». Предупреждение «приложение не проверено» — это ваше приложение: «Дополнительно → Перейти».

3. Раздел «Фото» — автозагрузка с телефона

Зачем куки и как их взять (2 минуты)

Фото из безлимитной автозагрузки видны только в разделе «Фото», а официальный API Яндекса их не отдаёт. Веб-версия Диска получает их плоским списком (с размером и MD5) и выдаёт ссылку на оригинал каждого файла — программа делает то же самое от вашего имени. Для этого нужны куки вашего входа в Яндекс. Файлы идут напрямую Яндекс → Google, на компьютер ничего не сохраняется.

  1. Поставьте расширение Cookie-Editor (Chrome / Яндекс.Браузер / Edge, Firefox).
  2. Откройте disk.yandex.ru/client/photo — там должны быть видны ваши фото.
  3. Нажмите значок 🍪 расширения → Export → Export as JSON (скопируется в буфер).
  4. Вставьте в поле ниже и нажмите «Сохранить и проверить».

Можно вставить и строку заголовка Cookie: … из инструментов разработчика (F12 → Сеть). Куки живут от нескольких дней до нескольких недель. Когда устареют, программа поставит на паузу только раздел «Фото» и напишет об этом. Остальные файлы продолжат переноситься. Обновите куки и нажмите «Старт». Куки — это доступ к вашему аккаунту: они хранятся только на этом компьютере, никому их не передавайте.

4. Список файлов

Программа получает у Яндекса готовый плоский список всех файлов: «Файлы» — официальным API, раздел «Фото» — как веб-версия. Ничего не скачивается, только список с размерами и MD5.
Перенос можно запускать сразу: файлы попадают в очередь по мере получения списка.

Настройки

Переносить раздел «Фото» (безлимит)
Не заливать повторно файл, который уже лежит на Drive (то же имя и MD5)
Проверять MD5 после загрузки
При запуске программы сам продолжать прерванный перенос
Число потоков применяется при следующем «Старте».
