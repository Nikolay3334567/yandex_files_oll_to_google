ЧТО ДЕЛАЕТ ПРОГРАММА
--------------------
Автоматизирует поштучное скачивание ваших собственных файлов с Яндекс Диска
и их резервное копирование на ваш Google Drive. Файлы скачиваются по одному,
под вашим собственным входом, с ограничением частоты запросов: через
официальный API Яндекса (по вашему токену) или через сайт Диска (по кукам
вашего входа).
  * раздел «Фото» (в том числе безлимитная автозагрузка с телефона) —
    в папку «Фото» на Drive, по годам и месяцам;
  * раздел «Файлы» — в отдельную папку на Drive с теми же папками;
  * каждый файл после загрузки сверяется по размеру и MD5;
  * прогресс сохраняется постоянно: после выключения света или перезагрузки
    перенос продолжается с того же места;
  * файлы, которые Яндекс сейчас не отдаёт, попадают в список «Отложенные»,
    их можно повторить позже одной кнопкой;
  * пробный замер скорости и разметка показывают, сколько займёт перенос
    и какие файлы Яндекс вообще отдаёт.
Программа только читает с Яндекса: на Яндекс Диске она ничего не удаляет
и не изменяет.


КАК ЗАПУСТИТЬ
-------------
1. Положите YandexToGoogle.exe в отдельную папку, например D:\YandexToGoogle.
   Рядом появится папка data с настройками, прогрессом и журналом.
2. Запустите exe. Если Windows покажет «Система Windows защитила ваш
   компьютер», нажмите «Подробнее» → «Выполнить в любом случае»: у программы
   нет платной цифровой подписи.
3. Откроются два окна. Чёрное окно — сама программа, не закрывайте его, пока
   идёт перенос. Второе — окно настроек и прогресса (его можно закрывать).
4. Настройте по шагам в окне: 1) токен Яндекса, 2) вход в Google, 3) куки
   сайта Диска (для раздела «Фото»), 4) буфер на диске (необязательно),
   5) список файлов. Затем нажмите «Старт». Подробные инструкции есть прямо
   в окне и в README на GitHub.

Проверка подлинности файла. Скачивайте exe только со страницы Releases
репозитория. Контрольная сумма SHA-256 указана там же (файл SHA256SUMS.txt).
Проверить её в Windows:
    certutil -hashfile YandexToGoogle.exe SHA256


ЧТО ВАЖНО ЗНАТЬ
---------------
* Не удаляйте ничего на Яндекс Диске, пока перенос не завершён и не сверен
  (блок «Проверка» в окне, «Полная сверка с Google Drive»).
* Нужно место на Google Drive: бесплатно Google даёт 15 ГБ, для большого
  объёма нужен платный тариф Google One.
* Google принимает не больше ~750 ГБ в сутки на аккаунт; на лимите программа
  сама ждёт и продолжает.
* Скорость зависит от Яндекса (он может отдавать файлы медленно или
  временно не отдавать часть файлов) и от вашего интернета на приём
  и на отдачу.
* Яндекс и Google могут в любой момент изменить свои API и правила — тогда
  программа может перестать работать полностью или частично.
